# Human Evaluation Rubric · Juno

_Module 5. Generated by `M5 - Human Evaluation Rubric.html`. Paste over `05-evals/human-rubric.md`._

## What graders score

- **What you’re scoring:** Juno's daily dashboard
- **Value proposition:** Turn the previous day's signals (emails, meeting notes, new documents, user feedback, metrics) into an analysis, roadmap, and records for each tool. Display these in a dashboard.

## Dimensions

| Dimension | Question | Scale | 1 or No | 3 | 5 or Yes |
|---|---|---|---|---|---|
| Accuracy (deal-breaker) | Does the dashboard content for a particular tool correctly correspond to that particular tool? | Yes / No | The data presented in the dashboard is completely or partially unrelated to the tool. This could either be the result of hallucination or the wrong data being pulled, for example data from another tool. | n/a | All data on the dashboard correspond to that particular tool - this includes analyses, consumer feedback, metrics, and roadmap. |
| Completeness (deal-breaker) | Are all the sections of the dashboard showing data? Does that data reflect new data from the day before (when applicable)? | Yes / No | Some dashboard sections are empty or do not contain the latest data. | n/a | All sections of the dashboard are filled with accurate data. When new data was created the day before (meeting notes, emails, new documents, updated documents, new metrics and consumer feedback pulls), these are reflected in the content of the dashboard. |
| Hallucination check (deal-breaker) | Is there data anywhere in the dashboard that is false or unverifiable?  | Yes / No | Data in dashboard does not match (or only partially matches) data in sources and/or there are missing sources for analyses. | n/a | Data in dashboard matches data in sources. This can be verified through the source links provided by Juno. |
| Usability | Is it clear what is the next step for a particular tool? | 1 to 5 | Dashboard does not indicate where the tool is on roadmap. Roadmap does not indicate what the next step is. | Either the status of the tool or the next step on the roadmap is missing. | Both the status of the tool and the next step on the roadmap are clearly indicated and written in a clear language. |
| User value | Would you share or trust this content? | 1 to 5 | Data is either incomplete, incorrect, or unverifiable | Data is complete, correct, verifiable but unclear | Data is complete, correct, verifiable, and clearly understandable |

## Calibration

- **How many answers you’ll score, and how often:** Check 2 answers a week (2 days). One on every Friday and one on a random day where known new data was produced the day before.
- **Who scores them with you:** PM and Manager
- **What happens when two of you disagree:** If our scores differ by two or more, review the question(s) where differences occurred and either modify the question(s) or correct and test Juno outputs.

## Pass bar

An average of 4 or higher on the 1 to 5 scale questions.  All Yes/No answers must be "Yes"

**Fails outright, whatever the average:**

- Accuracy: any "no"
- Completeness: any "no"
- Hallucination check: any "no"
- A single hallucination, missing data, or incorrect data is a fail.
